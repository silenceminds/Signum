# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` (`main`) | Yes |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities in `signum-edge`, `SMPv2`, `signum-agent`, or `signum-ctl`.

Instead, report vulnerabilities privately via **GitHub Private Vulnerability Reporting** at:
`https://github.com/silenceminds/Signum/security/advisories/new`

Include:
1. Component affected (`signum-edge`, `SMPv2`, `signum-agent`, `signum-ctl`, or firewall scripts).
2. Steps or proof-of-concept to reproduce.
3. Potential impact (e.g., mTLS bypass, SMPv2 frame forgery, SSRF, secret-scanner evasion, or memory disclosure).

We aim to acknowledge reports within 48 hours and coordinate a fix and advisory before public disclosure.
